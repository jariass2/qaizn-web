# Paleta Lima Energética - qaizn 🍃

## 🎨 Nueva Paleta Implementada

```css
:root {
    --cream: #FAFDF7;        /* Fondo principal - blanco verdoso */
    --black: #1F2D1A;        /* Texto principal - verde oscuro profundo */
    --coral: #A8D05D;        /* Acento principal - lima vibrante */
    --coral-light: #C8E89A;  /* Acento suave - lima claro */
    --beige: #F0F5E9;        /* Fondos secundarios - verde muy claro */
    --gray: #5A6B52;         /* Texto secundario - verde grisáceo */
}
```

## ✨ Características de la Paleta

### **Personalidad de Marca**
- 🌱 **Fresca y Energética**: El verde lima transmite innovación y vitalidad
- ♻️ **Sostenible**: Conexión natural con crecimiento y mejora continua (Kaizen)
- 🚀 **Moderna**: Paleta contemporánea perfecta para tech/IA
- 💚 **Optimista**: Color que inspira confianza y progreso

### **Psicología del Color**
- **Verde Lima**: Crecimiento, renovación, innovación, frescura
- **Verde Oscuro**: Estabilidad, profesionalidad, confianza
- **Blanco Verdoso**: Limpieza, claridad, espacio para respirar

### **Sectores Ideales**
- ✅ Empresas tech con valores sostenibles
- ✅ Startups innovadoras
- ✅ Consultoras de transformación digital
- ✅ Empresas que buscan diferenciarse
- ✅ Negocios enfocados en crecimiento

## 🎯 Por Qué Funciona para qaizn

1. **Conexión con Kaizen**: El verde representa crecimiento continuo
2. **IA Responsable**: Transmite tecnología con propósito
3. **Diferenciación**: Pocas empresas de IA usan verde lima
4. **Energía Positiva**: Inspira acción y optimismo
5. **Memorable**: El lima es más distintivo que azul/gris corporativo

## 🚫 Consideraciones

### Cuándo NO usar esta paleta:
- ❌ Sector financiero muy conservador
- ❌ Empresas que buscan máxima formalidad
- ❌ Audiencias muy tradicionales
- ❌ Mercados que asocian verde con "eco" únicamente

### Cuándo SÍ usar esta paleta:
- ✅ Quieres destacar en sector tech
- ✅ Audiencia joven o moderna
- ✅ Valores de innovación y sostenibilidad
- ✅ Diferenciación de competencia
- ✅ Transmitir energía y optimismo

## 🎨 Variaciones Posibles

Si el lima vibrante es demasiado intenso, puedes ajustar:

### Versión Más Suave
```css
--coral: #9AC556;        /* Lima más suave */
--coral-light: #BFD99A;  /* Lima muy claro */
```

### Versión Más Intensa
```css
--coral: #B5DC5F;        /* Lima más brillante */
--coral-light: #D4EDA8;  /* Lima pastel */
```

### Versión Más Profesional
```css
--coral: #8BB84E;        /* Verde hierba */
--coral-light: #B0D17A;  /* Verde claro */
```
